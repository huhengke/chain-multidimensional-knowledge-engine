### 2026-10-16 检索性能分层优化

- 知识脑查询不再把全部周存知识单元逐个做 Python `Decimal` 相似度扫描。新增可重建的树/日圈/星团投影索引：精确词项倒排和星团原型共振先产生有界候选，再由 WeKnora 混合召回与重排处理；日圈只在用户明确给出时间范围时参与交集过滤。
- 统一 Agent 的星团快速线索改为一次建立 `source_ref → 公共锚点` 反向表，避免“每个星团再次扫描全部跨脑边”的二次复杂度；命中的星团 ID 会传给知识脑，成为真实候选约束，不再只是页面展示。
- 统一 Agent 和知识专脑现在区分检索耗时、模型往返、首 token 和流式生成耗时。模型配置页的最近 50 次统计使用模型部署 ID 聚合；未启用流式或服务不返回 SSE 时不伪造生成耗时。
- 模型等待上限统一为 90 秒；本机持久化的结构化对话模型旧配置也已迁移到 90 秒，避免统一入口调用结构化子 Agent 时仍沿用历史 60 秒上限。
- 这轮代码回归中知识脑、聚类、统一 Agent、专脑 Agent 和模型统计测试通过；使用项目自带 `.runtime/platform-venv` 的完整测试已通过，外部全局 Python 环境缺少 `pypdfium2` 的两项 OCR 运行不作为本项目验收依据。该环境差异与本次检索优化无关。
- 新资料导入和知识分类纠偏完成后，会在发布拓扑快照前预热查询投影；启动恢复仍保留后台预热，避免首次提问承担历史日圈重建成本。
- 知识脑新增独立拓扑接口和独立 SVG 画布，没有复用结构化脑拓扑组件。拓扑由实际导入数据生成，覆盖来源文档、WeKnora 解析/父子分块/混合检索/重排、证据发布门、概念锚点、中通内链与周存单元、向量轨迹、DNA 外链、自动分枝、记忆星团、跨脑公共锚点和 generation 历史；不向前端暴露原始向量值。
