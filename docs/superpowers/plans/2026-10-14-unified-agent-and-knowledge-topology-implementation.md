# 统一 Agent 与知识独立拓扑实施计划

日期：2026-10-14

1. 扩展模型和统一会话契约，增加 `orchestrator` 模型用途、3+1 运行结构及兼容迁移。

4. 将现有 `/agent` 调整为统一 Agent 页面，复用成熟会话交互，新增专脑抽屉和固定 3+1 运行轨迹。
5. 从主导航隐藏三个专脑入口，保留稳定路由和返回统一会话能力。
6. 将知识拓扑升级为版本化的森林摘要及真实节点/边切片接口，覆盖 generation、分页、权限和恢复状态。
7. 实现知识专属森林、单树画布、工具栏、详情抽屉、查询路径高亮和结构台账。
8. 同步产品说明、模型配置说明和首次使用验收手册。
9. 执行后端定向及完整回归、前端类型检查和生产构建。
10. 在登录后的浏览器逐项验收统一路由、专脑跳转、知识画布、桌面/移动布局、字体对比度和控制台错误。
