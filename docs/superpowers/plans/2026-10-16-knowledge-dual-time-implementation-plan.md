# 知识脑双时间轴实现计划

## 目标

在不改变三个脑数据所有权边界的前提下，为知识数据推理脑增加内容时间抽取、知识时间维度星团、存入/观察时间与内容时间的联合查询，并让统一 Agent 根据查询类型选择单入口或自适应双入口交集。

## 实现顺序

1. 扩展知识契约和内存存储：加入内容时间锚点、导入时间和观察时间；保持旧字段兼容。
2. 新增确定性自动时间抽取器：读取元数据、标题、章节和正文，支持绝对时间、相对年份、区间和候选状态；记录来源定位和置信度。
3. 新增知识时间倒排投影：按年/月/日和区间建立 `temporal_cluster_id -> unit/evidence` 映射，支持局部重建和统计。
4. 扩展工作台搜索请求：支持内容时间范围、存入时间范围、时间入口和候选时间星团；保留已有 `start/end` 兼容语义。
5. 实现双入口查询规划器：单时间问题走单索引；双时间问题按候选规模选择并行交集或窄侧优先，并输出可观测的计划与耗时。
6. 接入统一 Agent：识别“昨天/最近”等观察时间和“去年/2024”等内容时间，将公共来源/单元/实体锚点求交后再生成答案。
7. 接入拓扑快照和查询结果：展示内容时间星团、两条时间轴和交集统计，但不把时间星团伪装成记忆星团。
8. 加入单元测试、平台 API 测试和导入回放测试，验证自动抽取、单入口、双入口、空交集、模糊时间和重启恢复。
9. 运行 `compileall`、完整 pytest、真实平台健康检查和双时间场景 smoke test；记录实际耗时，不用估算值替代。

## 关键约束

- 自动抽取不需要人工确认才能导入或发布；人工只用于观察和纠偏。
- 内容时间不写入 `TraceRecord.aggregate_key`，不破坏原有周存和生长身份。
- 内容时间星团不复制正文、向量、权限或其他大脑的事实库，只保存可重建引用。
- 不确定时间只能作为候选/语义线索，不能变成严格日期过滤条件。
- 结构化数据推理脑和多模态时空记忆脑保持原有处理逻辑；跨脑只通过外链和公共锚点。
