# 知识树文档分类修复

用户已确认：自动识别文档主领域，在领域内生成概念分枝；低置信度待归类；允许页面纠偏，并重建现有资料的树和星团。

## 边界与实现

- 仅修改知识脑。WeKnora 继续承担解析、父子分块、向量与混合检索；结构化脑、时空脑保持原实现。
- 分类先在文档层结合标题、标题层级和全文的多处领域依据，确定主领域。使用可解释、版本化的本地规则，分数是规则支持度，不宣称模型概率。无充分依据或领域冲突时保留待归类，不凭单个歧义词建领域树。
- 分类词匹配支持常用繁体表达；“形成本原”“保养生命”等不作为财务/设备依据。医疗领域覆盖中医术语。古籍不一律归医疗，支持人文典籍领域，证据不足的资料留待归类。
- 每份文档的知识单元继承主树；章节及领域内主题形成概念路径。其他领域命中保留为关联信息，不拆走主体知识；发布风险单独保留，不因人工更改分类降低发布门禁。
- 分类结果包含版本、主领域、支持度、依据、候选领域和人工覆盖记录。资产页显示结果和依据，管理员/操作员可填写原因纠偏或恢复自动分类，查看者不能修改。
- 重建使用已有正文及解析/向量缓存，原件、文档/单元/证据 ID 不变。完成后切换派生拓扑；旧快照存档，资产分类、拓扑和审计一起提交。保留发布审核记录，分类纠偏不等于发布批准。

## 实施与验收清单

1. 修复文档分类与知识单元归属，添加针对歧义词、繁体、混合领域、真实设备资料的回归测试。
2. 增加持久化分类结果、版本迁移、带权限与审计的纠偏接口；验证失败恢复、租户隔离、重启后人工覆盖保留、旧证据可定位。
3. 资产页显示分类和纠偏；树显示待归类及人文典籍，继续支持原有树图和关系图。
4. 用当前 19 个资产的只读输入预演，核对 11 份已索引文件的分类依据；备份当前数据库后部署，复用现有缓存重建，不重新上传文件。
5. 执行知识脑/平台相关测试、前端类型检查与构建，核对实际运行页面。记录实际结果与剩余限制。

## 验收重点

- 中医资料中的“形成本原”不建立财务树，养生“保养”及阴阳举例“温度”不建立设备树。
- 真正的设备维护、财务合同等文件仍能正常分类；不通过把所有资料强制归医疗解决问题。
- 同一文档在一棵主树内保留全部已解析单元，跨领域线索可追溯。
- 未知主题显式待归类，不捏造分类；不改变既有审批权限和证据可见性规则。
