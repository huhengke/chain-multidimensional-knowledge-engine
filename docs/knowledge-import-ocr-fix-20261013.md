## 已接入的能力

- `BAAI/bge-small-zh-v1.5` 本地 ONNX 中文向量模型；512 维，文件摘要锁定。
- `BAAI/bge-reranker-base` 本地重排模型，WeKnora 内部桥按真实模型分数重排。
- RapidOCR 3.8.1，PP-OCRv4 检测、方向分类与 PP-OCRv5 server 识别；文字页保留原文本，缺少文本的页面自动识别，竖排列序从右到左，列内从上到下。
- OCR 按账号、原件哈希、解析版本和模型文件摘要保存逐页检查点；重试复用已处理页，服务重启不会丢失原件和已完成页。
- 管理平台显示 OCR 页进度、向量索引进度、发布复核原因和摘要错误；模型配置支持真实向量及重排推理验证。
- 原文向量索引完成后，摘要和概念提取按有限长度分批、缓存结果；服务限流立即停止后续批次，不把整本书的剩余请求全部提交。重建工作区不再重新调用失败的外部摘要模型。

知识模型与 OCR 使用本工程 `.runtime/platform-venv` 和 `.runtime/standalone/models`。本地模型接口使用独立服务凭据，不复用结构化引擎服务密钥。原有结构化脑和时空记忆脑配置、业务数据未修改。

模型来源和技术接口参考：[FastEmbed 模型目录](https://qdrant.github.io/fastembed/examples/Supported_Models/)、[RapidOCR PP-OCRv5 接入文档](https://rapidai.github.io/RapidOCRDocs/main/install_usage/rapidocr/how_to_use_ppocrv5/)。下载、锁定及启用步骤见 `scripts/setup-knowledge-local.ps1`。
